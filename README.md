# LearnPlaywrightBatch2X

Welcome to **LearnPlaywrightBatch2X** — a structured learning repository for mastering JavaScript fundamentals and Playwright automation testing. This repo is organized into chapters that progressively build your knowledge from basic concepts to advanced automation topics.

## Chapters Overview

### Chapter 01 — Basics
Introduction to JavaScript, basic commands, and hot code examples to get started.

### Chapter 02 — JavaScript Concepts
Core JavaScript concepts including variables, data types, and fundamental programming building blocks.

### Chapter 03 — Identifier & Literals
- **Identifier Rules**: Understanding valid naming rules for variables and functions
- **Naming Conventions**: camelCase, snake_case, PascalCase, SCREAMING_SNAKE_CASE, and more
- **Comments**: How to write single-line and multi-line comments
- **VS Code Shortcuts**: Quick reference keyboard shortcuts for both Mac and Windows

## How to Use This Repository

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sasala25/LearnPlaywrightBatch2x.git
   cd LearnPlaywrightBatch2x
   ```

2. **Navigate through chapters**
   Each chapter builds upon the previous one. Start from `Chapter_01_Basics` and progress sequentially.

3. **Run JavaScript files**
   You can run any `.js` file using Node.js:
   ```bash
   node Chapter_01_Basics/01_Basic.js
   ```

4. **Use VS Code shortcuts**
   Check the shortcut reference files in `Chapter_03_Identifier_Literals` to speed up your workflow.
