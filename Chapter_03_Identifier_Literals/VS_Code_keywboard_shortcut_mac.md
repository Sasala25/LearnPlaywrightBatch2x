## Emmet

| Action | Shortcut |
|--------|----------|
| Expand Abbreviation | `Tab` |
| Wrap with Abbreviation | `Cmd + Shift + A` |
| Remove Tag | `Cmd + K, T` |
| Update Image Size | `Cmd + Shift + I` |

| Decrement by 10 | `Opt + Down` |

> **Note:** Comma-separated shortcuts like `Cmd + K, S` mean press `Cmd+K` first, release, then press `S`.
> **Mac Key:** `Cmd` = Command, `Opt` = Option/Alt, `Ctrl` = Control
